# Query 04：误导文本下的视觉判断——额外难题改造指导

本指导只补充当前 Generator 的作者侧设计与审查要求。保持原任务、子任务能力、事实依据、样本 schema 和答案类型；按当前素材选择合适方向，不要求每题覆盖全部机制，不增加固定步骤或输出字段。本指导及内部分析不进入最终题面。

目标是让模型结合具体视觉证据，区分文本中可信的观察和错误的解释。难度应来自可信近邻解释之间的竞争，以及决定它们的视觉关系。

1. **以真实观察支撑一个关键误解。** 误导文本先保留真实的对象、外观或场景线索，再把其中一个属性、关系或推断解释错，让错误结论具有吸引力。正确判断应保留有依据的部分并纠正关键错误。避免只添加一个显眼的不存在物体，或把整段话写得明显荒谬。

2. **优先开发精细关系与属性归属。** 从原图寻找支撑与悬挂、桥内与桥上、布料在身体之前与之后、衣摆与腰带、按钮颜色与面板底色、同一柜体与邻接柜体等可区分关系。这些只是方向示例，不能据此声称当前图片存在相应细节。让可见边界、连接、位置或姿态相互约束，决定哪个解释成立；避免只凭一个物体名称或常识就选出答案。

3. **区分可见状态与因果、意图、时间。** 静态照片中的朝向、坐姿、邻近或聚集，不自动证明服从口令、认出自己、上下车方向或此前发生的动作。误导解释可以利用这种自然联想，但正确答案须准确保留可观察事实，并限定具体未获支持的推断。原图足以支持的关系也应明确回答，避免把所有题都改成泛泛的“无法确定”。

4. **利用局部与整体、对象边界及计数单位的混淆。** 素材适合时，让“部分”被误读成“全部”、“同一物体的一部分”被计成额外物体，或相邻区域的属性被移给目标。判定范围、对象单位与图像编号须清楚，关键证据应实际可辨；不能靠模糊指代、低清细节或争议标注制造错误。

5. **让选项在关键区别上竞争。** 对选择题，保留共同的真实观察，围绕决定答案的属性归属、空间关系或推断强度设计平行且可信的替代解释。最强干扰项应对应误导文本诱发的具体误读，能由图中证据或明确的证据边界排除。避免“最长且最谨慎的一项”固定为正确答案、正确项包揽全部事实、其余项各含明显常识错误。增加选项、独立核验更多事实或加长文字本身不构成更难的判断。

6. **用实际解题路径检查改造效果。** 提案与 Design 说明当前素材的关键视觉依据、可信误解和两者的决胜区别；Construct 落实该区别，避免把决定性视觉事实或正确分析写进文字替模型作答。初审检查是否能仅凭文本措辞、默认反对陪文或一律选择不确定而答对，并为当前题给出具体改法；Repair 保留有效挑战，终审核对完成后的证据与唯一答案。不要求新增审计表，也不能仅因未使用某个建议方向而拒绝样本。

保留素材中有价值的复杂性，同时确保原图与可信依据支持判定。沿用、借鉴错误类型，不复制已有错题的内容、答案位置或特定模型回答；不声称未经实测的难度提升。
